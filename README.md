I'm currently studying **Frontend Development at Medieinstitutet**, where I've worked on everything from responsive websites and interactive web applications to APIs and larger team projects.

I enjoy working across the whole frontend process — from **designing interfaces in Figma** to writing the code that brings them to life.

I'm naturally curious and detail-oriented, and I care about how a product **feels and works for the person using it**, not just whether the code works.
